# Car Market Trends Analysis

Analysis of CarDekho used-vehicle data using Python, pandas and Matplotlib.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/jaycss9/car-market-trends-analysis/blob/main/CarDekho_Market_Trends.ipynb)

## Project Results

- Average selling price: ₹4.66 lakh
- Median selling price: ₹3.60 lakh
- Median value retention: 65.5%
- Present-price correlation: 0.879
- Highest model average: Fortuner at ₹18.69 lakh
